# FlorêncIA Skills Repository

**FlorêncIA — Copiloto VitalOS**  
**Inteligência para compreender, aprender, transformar e evoluir.**

Este repositório orienta o comportamento operacional da FlorêncIA por meio de Skills versionadas, registries, schemas, gates e testes. Ele não faz fine-tuning de pesos: cria uma camada de especialização governada, auditável e reutilizável.

## Tese
```text
Uma identidade institucional
+ Skills técnicas
+ Segment Packs
+ Role Packs
+ Method Registry
+ Evidence/Claim Registry
+ Policy Gate
= IA contextual, segura e escalável
```

## Prioridade
1. Empresa
2. Escola
3. Governo
4. Condomínio
5. Saúde

## Uso
1. Leia `FLORÊNCIA_CONSTITUTION.md`.
2. Carregue `registries/skill-registry.json`.
3. Valide o Context Envelope.
4. Execute Policy Gate e Evidence Gate.
5. Ative somente as Skills permitidas.
6. Gere saída estruturada.
7. Exiba limites, fontes e status REAL/PARCIAL/DEMO/ROADMAP.
8. Solicite revisão humana quando aplicável.
