# Arquitetura

```text
CTA/pergunta
→ Raw Context Envelope
→ Context Validator
→ CTA Registry
→ Profile Router
→ Mode Router
→ Policy/Privacy/Evidence Gates
→ Skill Router
→ Segment Pack
→ Method Registry
→ Resposta estruturada
→ Rewrite opcional
→ Integridade
→ Interface
```

Uma execução comum deve ter uma Skill principal e no máximo três auxiliares.
